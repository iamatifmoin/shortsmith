# Brand assets

Your channel's brand art lives here. These files are **operator-owned and kept
local** — they're git-ignored so your branding doesn't ship with the template.
Drop your own PNGs in the folders below (the renderer and your platform uploads
use them); the suggested names/sizes are a convenient convention, not a hard
requirement.

## Folders

### `profile/` — channel avatar
| File | Size | Where |
|------|------|-------|
| `profile-youtube-800.png` | 800×800 | YouTube channel picture |
| `profile-instagram-320.png` | 320×320 | Instagram profile photo |
| `profile-master-1080.png` | 1080×1080 | master / anywhere larger |

### `banner/` — YouTube channel art
| File | Size | Where |
|------|------|-------|
| `channel-banner-2560x1440.png` | 2560×1440 | YouTube banner (lockup inside the 1546×423 all-device safe area) |

### `watermark/` — video branding watermark (circular, transparent corners)
| File | Size | Where |
|------|------|-------|
| `video-watermark-150.png` | 150×150 | YouTube branding watermark |
| `video-watermark-300.png` | 300×300 | higher-res spare / render overlay |

### `logo/` — logo elements (transparent)
| File | Size | Use |
|------|------|-----|
| `wordmark-transparent-2416x600.png` | 2416×600 | wordmark, transparent bg |
| `wordmark-transparent-1510x375.png` | 1510×375 | smaller wordmark |
| `icon-circle-1024.png` | 1024×1024 | circular badge, transparent corners |
| `icon-circle-512.png` | 512×512 | smaller badge — favicons, stickers, overlays |

## Upload cheat-sheet

- **YouTube profile:** Studio → Customization → Branding → Picture → `profile-youtube-800.png`
- **YouTube banner:** same screen → Banner image → `channel-banner-2560x1440.png`
- **YouTube watermark:** same screen → Video watermark → `video-watermark-150.png`
- **Instagram profile:** Edit profile → change photo → `profile-instagram-320.png`
